# nsh

The New Human Shell. Type a Bash command. If it fails in a terminal, YHWH
asks what you meant. Answer in place, or type **:cancel** to get back to Bash.
Use **ld.so COMMAND** to run Bash without that conversation. Noninteractive
invocations are ordinary Bash.

**NSH** is the English spec. **LD NSH > nsh.new** produces a shell file you
can read, test, and install. **nhs** is another name for the shell.
